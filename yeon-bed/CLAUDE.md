# 연 — 침대 지수 화면 (고슴도치 버전)

## 이 프로젝트를 맡은 Claude에게
- 사용자는 **코딩을 전혀 모르는 기획자**다. 설명은 한국어로, 쉬운 말로, 짧게 한다. 코드 용어는 꼭 필요할 때만 쓰고 풀어서 설명한다.
- 한 번에 크게 바꾸지 말고 **작게 바꾸고 → 미리보기로 보여 주고 → 확인받는** 순서로 간다.
- 바꾼 뒤에는 무엇이 달라졌는지 화면 기준으로 말한다("침대 아래에 ~가 생겼어요").
- 사용자가 "별로"라고 하면 바로 이전 상태로 되돌릴 수 있게, 바꾸기 전에 git으로 커밋해 둔다.

## 실행 방법
이미지를 캔버스로 처리해서 파일을 그냥 더블클릭하면 안 된다. 로컬 서버로 연다.
```
python3 -m http.server 8000
```
→ 브라우저에서 http://localhost:8000 (데스크톱 앱이라면 Preview 사용). 모바일 기준(폭 390px)으로 확인한다.

## 파일 구성
- `index.html` — 메인 화면. 침대 지수, 고슴도치, 이불 당기기, 사주 말풍선, 머리 방향 설정, "우리 집" 배너. CSS·JS가 한 파일 안에 있다(나중에 나눠도 됨).
- `chat.html` — 서브 화면. "우리 집" 단톡방(나·고슴도치·사주) + 이야기 인물(서하) + 모습 바꾸기. `index.html`이 `chat.html?embed=1`로 띄운다.
- `assets/bed-stages.webp` — 이불 5단계 사진(한 장에 5개). `assets/hog-faces.webp` — 고슴도치 표정 5장(한 장에). `assets/faces/*.webp` — 대화 아바타. `assets/chat-bed-card.webp` — 대화 속 침대 사진 카드.
- 화면 아래 "점수 테스트" 박스는 확인용이다. 사용자가 말하기 전까지 지우지 않는다.

## 서비스와 화면의 기조 (바꾸지 말 것)
- 연: 사주 × 날짜 × 장소 × 사람으로 오늘을 읽어 주는 모바일 웹. 브랜드 문장은 "사주가 먼저 한마디 합니다". 타깃은 내향형.
- **고슴도치는 나가기 싫어하는 게 기조.** 나가라고 하는 건 늘 사주다. 고슴도치는 끝까지 내 편.
- **나가면 표정만 삐지고 상태는 안 바뀐다.** 배고픔·레벨·성장·죽음 같은 수치 없음. 돌보지 않아도 불이익 없음.
- 침대 지수 = 버티는 횟수(78점 → 78번째 당김에 나옴). 대사 99개 + 100번째. 50 미만은 이불이 사람을 붙잡는 버전(대사 별도).
- 고슴도치 말풍선은 **아이폰 받은 메시지** 스타일(회색, 왼쪽 꼬리, 처음엔 입력 중 점 세 개).
- **침대 화면이 메인, 단톡방은 서브.** 단톡방에서 사주는 멤버로 매일 먼저 말한다.
- 귀인·좋은 방위는 **침대 위에 그리지 않는다.** 위쪽 태그의 화살표로만 방향을 가리킨다.
- 동거인 = "내 사주로 태어난 동거인". 영혼은 하나, 모습(고슴도치·거북이·고양이…)만 바뀐다. 모습은 쿠키로 판매, 바꿔도 대화·기억은 이어진다.
- 소설·연 오리지널 속 인물은 동거인과 섞지 않고 **새 연락처(대화방)**로 생긴다. 인물도 사주가 있어 오늘 지수·나와의 궁합이 있다.
- 미감: 흰 바탕, 위에서 찍은 실사 오브제. 침구는 흰 면(살짝 크림빛). 이전에 젖빛 유리·얇은 세리프 시도는 사용자가 별로라고 해서 되돌렸다.

## 알려진 문제
- 침대·고슴도치 원본 해상도가 작다(침대 하나 폭 약 300px). 근본 해결은 단계별·표정별로 폭 1000px 이상 이미지를 새로 만드는 것.
- 고슴도치가 이불 "속"에 있는 느낌(부피·그림자)이 없다 → 고슴도치가 들어간 이불 단계 사진을 새로 만들어야 해결.
- 눈금 간격이 고르지 않다(실제 이불 높이에 맞췄기 때문).
- 풀이 문장·방위·서하 등은 전부 예시 데이터다.

## 다음에 할 일 (우선순위)
1. **고슴도치가 먼저 말 걸기**: 화면에 들어오면 고슴도치 머리 위에 입력 중 점(…) → "왔어?" 말풍선. 이 말풍선을 누르면 단톡방이 열린다.
2. **살아 있는 느낌**: 숨쉬듯 몸이 살짝 오르내림, 몇 초마다 표정 바뀜(표정 5장 활용).
3. **만지면 반응**: 고슴도치 얼굴을 누르면 쓰다듬기(표정+대사), 이불을 누르면 당기기로 나누기.
4. 단톡방으로 이어지는 장치: 몇 초 뒤 위에서 내려오는 알림 배너(질문형 미리보기), 이불 당기기가 끝나면 "고슴도치가 할 말 있대 →".
5. 나중에: 이름 짓기, "도치 · 이불 속 · 방금 전" 상태 표시, 첫 방문 인사.
